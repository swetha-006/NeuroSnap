ℹ️ About NeuroSnap

CNN-based brain tumor detection — project overview

🧠 Project Overview

NeuroSnap is a deep learning system that classifies brain MRI scans as Tumor Detected or Normal Brain using a Convolutional Neural Network (CNN) trained on real MRI images. The model is served through a Flask web application, enabling instant predictions from any browser.

Built as a Deep Learning mini-project by a student. For educational purposes only.
